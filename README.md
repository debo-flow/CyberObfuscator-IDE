# 🛡️ CyberObfuscator Ultimate | Enterprise AST IDE v6.3

A powerful, offline-safe, browser-based JavaScript obfuscation and AST (Abstract Syntax Tree) transformation IDE. Built entirely with Vanilla JavaScript, HTML, and CSS, this tool runs directly in the browser without needing a backend.

## 🚀 Live Demo
[Click here to use the IDE Live](https://debo-flow.github.io/CyberObfuscator-IDE/)

## ✨ Key Features

* **Multi-Pass Transformation Engine:** Parses, analyzes, normalizes, transforms, optimizes, and generates code in a highly structured pipeline.
* **Advanced Obfuscation Passes:**
  * Scope-Aware Identifier Renaming
  * Dynamic Base64 String Pooling
  * Numeric XOR Encoding & Boolean Transformation
  * Control Flow Flattening
  * Self-Defending Code & Advanced Anti-Debugging (Devtools block)
* **Custom Workspace Plugins:** Write and inject your own custom AST transformation plugins directly in the editor using Babel plugin syntax.
* **Build Telemetry & Diagnostics:** Get detailed execution statistics, AST node count, memory usage, and execution time per pass.
* **Modern IDE Experience:** Features Monaco Editor, a Command Palette (Ctrl+Shift+P), Draggable Dockview layout, and multiple UI themes (Midnight, Light, Default).

## 🛠️ Tech Stack

* **Core Engine:** Babel Standalone
* **Editor & Layout:** Monaco Editor, Dockview Core
* **Storage & Utilities:** LocalForage, Sortable.js
* **UI/UX:** Vanilla JS, Lucide Icons, Xterm.js

## 💡 Why this project?
Unlike traditional web services, this Enterprise AST IDE provides a completely offline-safe environment for developers to experiment with JavaScript AST manipulation, write custom compiler plugins, and understand how code obfuscation works under the hood.
